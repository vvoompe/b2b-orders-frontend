# Система підтримки ухвалення рішень щодо B2B-замовлень - клієнтська частина

Індивідуальний STEM-проєкт з ОК «Розробник фронтенду програмних систем» (КНУ ім. Тараса
Шевченка, ФІТ, кафедра програмних систем і технологій).

**Виконавець:** Олександр Маркграф, група ІПЗ-31 (підгрупа 1).
**Тема:** розроблення клієнтської частини системи підтримки ухвалення рішень щодо
B2B-замовлень засобами React.

Менеджер B2B-продажів замість «сухого» списку замовлень бачить **прогноз імовірності
успішного закриття** кожного замовлення, **чинники**, що на прогноз вплинули, і може
**перерахувати прогноз** після зміни умов. Аналітик додатково бачить метрики якості моделі та
важливість ознак, адміністратор - керує ролями користувачів.

## Швидкий старт

```bash
cd app
npm ci          # або npm install
npm run dev     # http://localhost:5173
```

Демо-доступи: `manager@demo.ua` / `manager123`, `analyst@demo.ua` / `analyst123`,
`admin@demo.ua` / `admin123`. Детальніше - в [app/README.md](app/README.md).
